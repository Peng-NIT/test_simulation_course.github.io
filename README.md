# 大语言模型驱动的强电检修双臂机器人虚拟仿真实验

本仓库为课程实验的独立介绍网站，使用原生 HTML、CSS 与 JavaScript 构建，可直接通过 GitHub Pages 发布。

当前页面对应最新版实验内容，重点展示学生/教师双角色入口、双 6DOF 机械臂任务、可调带电区域与上方高压线约束、大语言模型生成 PDDL 草稿、课程范围内的大语言模型问答，以及 MuJoCo 错误示范与安全验证。页面将 AI 生成 PDDL 作为主要动态案例，同时保留学生自主编写入口，并提供可操作的选择填空示例和三类错误诊断案例，用于解释代码与学生答案如何影响规划和仿真。

网站只承担项目介绍与教学演示。实际 Streamlit 实验程序独立运行，其访问地址统一配置在 `config.js`：

```javascript
window.SITE_CONFIG = {
  streamlitAppUrl: "https://your-app.streamlit.app"
};
```

在 GitHub Pages 中将发布源设置为 `main` 分支根目录即可。


## 页面底部访问量

访问量直接展示在首页底部，采用浅色背景与大号数字，滚动到访问量区域时快速滚动并逐位减速定格，每次页面载入仅播放一次；初始值为 1000，每次进入或刷新首页随机增加 1–9，普通点击、滚动不会重复计数。支持系统“减少动态效果”设置。

### 所有访客共享累计值

运行 `python3 server.py --port 8000`，浏览器打开 `http://127.0.0.1:8000`。服务通过 SQLite 事务保存访问量，支持并发更新和重启后保留；数据位于 `.data/visits.sqlite3`，请持久保存并备份该文件。正式部署需运行该服务并通过反向代理对外提供 HTTPS；按部署环境设置 `--host` 和 `--port`。

接口：`POST /api/visits` 随机增加 1–9 并返回 `{"total":1005}`；`GET /api/visits` 仅读取。页面默认调用同源 `api/visits`。如有自有计数接口，可在 `config.js` 设置 `visitsApiUrl`；接口必须返回相同格式并允许页面跨域访问（若跨域部署）。

### GitHub Pages 或直接打开文件

GitHub Pages 无法运行 Python/SQLite 服务。计数接口不可用时，页面回退到当前浏览器的本地存储，并在数字下方显示“当前浏览器的访问记录”；此时不同设备不共享累计值，清除浏览器数据会重置计数。存储被禁用时仅本次页面有效。上线后若要共享计数，需部署上述服务或配置兼容接口。
